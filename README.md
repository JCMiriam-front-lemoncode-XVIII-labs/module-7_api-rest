# ⚡ Api rest - LAB

Este repositorio contiene la resolución de los ejercicios propuestos en el  `Módulo 7 - Api rest`.

El proyecto incluye:

- Adaptación del **Boilerplate** como punto de partida
- Cambio de escenas, rytas y pods a `character-collection` y `character`
- Obtención de personajes a través de la API Rest de Rick & Morty
- Detalle del personaje al editar desde el botón de la card
- Simulación de escritura a través del server del proyecto
- Campo editable `bestSentence`
- Paginación
- Buscador
- Escenas (con sus respectivos componentes) de `locations` y `episodes`
